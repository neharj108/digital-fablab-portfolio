Day 04

Switch Cases

Day four focused on a cleaner way to handle multiple fixed conditions, moving beyond long chains of if-else.

  • Learned switch-case as a cleaner alternative to long if-else chains
  • Practiced the traditional switch statement with break
  • Explored the modern Java switch expression using arrow syntax and yield
  • Handled default cases and grouped multiple labels together
Day4_SwitchCase.java 
public class Day4SwitchCase {
    public static void main(String[] args) {
        int day = 3;
        String dayName;

        switch (day) {
            case 1 -> dayName = "Monday";
            case 2 -> dayName = "Tuesday";
            case 3 -> dayName = "Wednesday";
            default -> dayName = "Unknown";
        }

        System.out.println("Day " + day + " is " + dayName);
    }
}

🔍 What We Learned

  • Understood when switch-case is a better fit than if-else chains
  • Compared the traditional and modern switch expression syntax
  • Practiced handling default and grouped case labels correctly

The final day — turning the Day 6 plan into a fully working Java program, tested with real input and edge cases.

  • Added grade logic with if-else and formatted the final report using printf

  • Module wrapped — ready to move on to Networking and IoT next!
GradeCalculator.java 
import java.util.Scanner;

public class GradeCalculator {
    static char getGrade(double pct) {
        if (pct >= 90) return 'A';
        else if (pct >= 75) return 'B';
        else if (pct >= 60) return 'C';
        else if (pct >= 40) return 'D';
        else return 'F';
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Number of subjects: ");
        int n = sc.nextInt();
        int[] marks = new int[n];
        int total = 0;

        for (int i = 0; i < n; i++) {
            System.out.print("Marks for subject " + (i + 1) + ": ");
            marks[i] = sc.nextInt();
            total += marks[i];
        }

        double pct = (total * 100.0) / (n * 100);
        System.out.printf("%nTotal: %d | Percentage: %.2f%% | Grade: %c%n",
                total, pct, getGrade(pct));
    }
}
