UI / UX Design

Designing intuitive, beautiful interfaces with Figma — from wireframes to polished prototypes.

✦ Completed 🎨 Figma ✦ Prototyping 📐 UX Research 7 Days
Day 01

Installation & Introduction to Figma

Getting started with the industry-standard design tool — setting up the workspace and understanding core UI/UX concepts.

  • Installed Figma desktop app & created an account
  • Understood the difference between UI (User Interface) and UX (User Experience)
  • Explored the Figma interface — toolbar, layers panel, properties panel
  • Learned about Pages, Frames, and Canvas in Figma
  • Introduction to design thinking: empathize, define, ideate, prototype, test
  • Explored real-world UI examples to understand good vs poor design

Day 02

Frames, Colors & Typography

Building the visual foundation — creating frames for different devices and applying colors and text to bring layouts to life.

  • Created Frames for desktop, tablet & mobile screen sizes
  • Used the Rectangle, Ellipse, and Polygon shape tools
  • Applied Fill colors — solid, linear gradient, radial gradient
  • Added Text layers and explored font families, sizes & weights
  • Understood Stroke, Corner Radius, and Opacity settings
  • Practiced grouping elements and naming layers for clean file organization
  • Explored the Color Styles feature to create a consistent color palette
Output
Session
Day 03

Red Bull UI — Layout & Glass Morphism

Starting the Red Bull UI project — building the hero layout and mastering the glass morphism effect for a premium, modern aesthetic.

  • Started the Red Bull UI Design project from scratch in Figma
  • Set up a dark-themed frame with brand colors (Red Bull red, black, silver)
  • Placed & positioned brand imagery using Image Fill on shapes
  • Used Auto Layout to structure the navigation bar responsively
  • Created glass morphism cards — semi-transparent frames with Fill Opacity set to 10–20%
  • Applied Background Blur effect to achieve the frosted glass look
  • Added Stroke with low opacity white border to complete the glassmorphism style
  • Layered elements with shadows using Drop Shadow & Inner Shadow

Day 04

Red Bull UI — Components & Refinement

Continuing the Red Bull project — building reusable components, refining the layout and polishing every design detail.

  • Created reusable Components for buttons, cards & the nav bar
  • Used Variants to create hover and active states for buttons
  • Designed a product showcase section with overlapping image layers
  • Used Clip Content on frames to mask overflowing images cleanly
  • Refined the glass morphism cards with better contrast & readability
  • Explored Effects panel — blur, drop shadow & layer blending modes
  • Linked multiple frames together to form a complete screen flow

Day 05

Prototyping & Animations

Making the design interactive — linking screens and applying Figma's animation settings to create realistic, smooth transitions.

  • Switched to Prototype mode and connected frames with interaction arrows
  • Set triggers: On Click, On Hover, Mouse Enter, Mouse Leave
  • Chose animation types: Instant, Dissolve, Smart Animate, Move In / Move Out, Push, Slide In / Slide Out
  • Configured Easing curves — Ease In, Ease Out, Ease In & Out, Linear, Spring
  • Set animation Duration (in milliseconds) for each transition
  • Used Smart Animate to auto-animate shared layers between frames
  • Applied Scroll Behaviour — fixed position for navbar during scroll prototype
  • Previewed the full prototype flow using Figma's built-in Presentation Mode
Output
Session
Day 06

UX Fundamentals & Case Studies

Going beyond visuals — learning the science of user behaviour, usability principles, and analysing real-world UX through case studies.

  • Studied core UX principles: Usability, Accessibility, Consistency, Feedback
  • Understood the patterns and flow of how users read screens
  • Analysed UX case studies — Linkedin, Go Daddy & popular e-commerce apps
  • Discussed common UX mistakes: poor contrast, hidden CTAs, cluttered layouts
  • Introduced to User Personas and User Journey Mapping
Output
Day 07
✦ Final Project

Final Project — Complete UI/UX Design

The culmination of the entire module — designing a complete, polished UI with a working prototype, ready to be handed off to a developer.

  • Designed a complete multi-screen UI project from concept to prototype
  • Applied all module learnings — layouts, components, glass morphism & animations
  • Built a consistent design system with Color Styles & Text Styles
  • Created a fully linked interactive prototype with smooth transitions
  • Conducted a self-review using UX heuristics to refine the design
