Laser Cutting

From vector design to precision-cut parts — mastering the laser cutter from machine basics to final project

✦ Completed ✂️ CO₂ Laser 6 Days LightBurn · DXF · SVG
Day 01

Introduction to the Laser Cutter

The first day focused on understanding the machine — what a CO₂ laser cutter is, how it works physically, all of its components, and the critical safety rules that must always be followed.

  • Understood what a CO₂ Laser Cutter is — a machine that uses a focused beam of infrared laser light to cut or engrave materials with extreme precision
  • Learned how the laser beam is generated in the CO₂ tube and directed via mirrors to the focusing lens above the cutting head
  • Identified all machine components: Laser Tube, Beam Path Mirrors, Focusing Lens, Cutting Head, Honeycomb Bed, Air Assist, Exhaust Fan, and Controller Board
  • Understood the difference between Cutting (full-power, slow pass) and Engraving (lower power, fast raster scan)
  • Learned about compatible materials: Acrylic, Wood (MDF, Plywood), Cardboard, Leather, and materials that must never be cut (PVC, polycarbonate — they produce toxic fumes)
  • Studied all safety rules: never leave the machine unattended, ensure exhaust ventilation is running, keep fire suppression nearby, never bypass the lid interlock
  • Understood the role of Air Assist — a constant stream of air blown at the cut point to reduce burning and keep the lens clean

🔍 What We Learned

  • Identified all physical components of the CO₂ laser cutter by name and function
  • Learned the critical safety rules before ever operating the machine
  • Understood the difference between cutting and engraving modes

Day 02

Machine Operation & Settings

Learning to operate the laser cutter — setting up the material, focusing the beam, and understanding power and speed settings that determine the quality of every cut.

  • Learned how to set the focal length — adjusting the cutting head height using a focus tool so the laser beam converges precisely at the material surface
  • Placed material flat on the honeycomb bed and secured it to prevent movement during cutting
  • Used the machine's Control Panel to set the laser Origin (start position) and frame the job before cutting
  • Understood the two key settings: Power (%) — how intense the beam is, and Speed (mm/s) — how fast the head moves
  • Learned the relationship: high power + slow speed = deep cut, low power + fast speed = surface engrave
  • Ran test cuts on scrap material to find the correct power/speed combination for the actual material thickness
  • Understood the Z-height offset adjustment for materials of different thicknesses
  • Ensured the exhaust system was running and the air assist was connected before any cuts

🔍 What We Learned

  • Learned all the operational steps — focusing, origin setting, framing, and running a job
  • Understood how power and speed settings affect cut depth and quality
  • Ran test cuts to find optimal settings for the project material

Day 03

Design Software & File Preparation

Learning to prepare files for the laser cutter — understanding what file formats the machine accepts, how to use LightBurn software, and how to convert a CAD file into a laser-ready job.

  • Introduced to LightBurn — the primary software used to control the laser cutter and prepare cutting jobs
  • Understood that the laser cutter cuts along vector paths — so designs must be created as vector files, not raster images
  • Learned about accepted file formats: DXF (from Fusion 360 or AutoCAD), SVG (from Inkscape or Illustrator), and AI
  • Opened a DXF file exported from Fusion 360 into LightBurn — understood the import process and how to check for open paths or duplicate lines
  • Assigned layers in LightBurn — each color represents a different operation (cut, engrave, score) with its own power/speed settings
  • Used the Node Editor in LightBurn to fix open paths that would cause incomplete cuts
  • Learned the difference between Line mode (vector cut/score) and Fill mode (raster engrave)
  • Set up the job layout — placed parts efficiently to minimize material waste using the Arrange tools
  • Previewed the job in LightBurn's Preview window to verify cut order and estimated job time

🔍 CAD → DXF → LightBurn Workflow

  • Exported a Fusion 360 sketch as a DXF file and imported it into LightBurn
  • Assigned cut layers with correct power and speed settings per operation
  • Previewed the job and verified the cut path before sending to the machine

Day 04

First Cut — Project Day 1

Putting everything together — running the first real cut on the project material and beginning the fabrication of the final project.

  • Placed the chosen project material (MDF / acrylic sheet) on the honeycomb bed and set focus
  • Sent the prepared LightBurn job to the machine and ran the Frame preview to confirm positioning
  • Started the cut job and monitored the process — watched for flame flare-ups or stalling
  • After cutting, carefully removed parts from the bed and cleaned up the kerf edges
  • Checked part dimensions with calipers against the original design dimensions
  • Identified any cut quality issues — charring, incomplete cuts, or melted edges — and noted adjustments for the next run

✂️ Project Work — Day 1

  • Successfully ran the first laser cut of the project parts
  • Verified cut quality and dimensions against the original design
  • Noted settings improvements for the next cut session

Day 05

Project Continues — Engraving & Refinement

Expanding the project — adding engraved elements, cutting additional components, and refining the fit and finish of all cut parts.

  • Added engraving to project parts — logo, text, or decorative patterns using LightBurn's Fill mode
  • Cut remaining project components on fresh material sheets
  • Post-processed cut parts — cleaned charred edges with fine-grit sandpaper or a damp cloth
  • Dry-assembled all parts together to verify fit — checked slot widths, tab thicknesses, and joint clearances
  • Understood the importance of accounting for kerf width — the material removed by the laser beam — when designing tight-fitting joints
  • Made small CAD adjustments to improve the fit of one component that was slightly too tight

✂️ Project Work — Day 2

  • Added engraved details to project parts using LightBurn's Fill mode
  • Cut all remaining components and cleaned up edges
  • Dry-assembled the full project and verified all joints fit correctly
