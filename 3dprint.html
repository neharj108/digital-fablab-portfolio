Module 04 · FDM Printing

3D Printing

From CAD file to physical object — mastering FDM 3D printing from machine basics to slicing and printing

✦ Completed 🖨️ FDM Printing 6 Days Cura · PLA · STL
Day 01

Introduction to the 3D Printer

The first day was all about getting familiar with the machine itself — understanding how an FDM 3D printer works and what all its physical components do before touching any software.

  • Learned what FDM (Fused Deposition Modeling) is — a process that builds objects layer by layer by melting and depositing thermoplastic filament
  • Identified all major printer parts: Frame, Print Bed, Extruder, Hotend, Nozzle, Stepper Motors, and Control Board
  • Understood the role of the X, Y, and Z axes — how the print head and bed move during printing
  • Learned about filament types — PLA, ABS, PETG, and TPU — and why PLA is the most common starting material
  • Observed the printer homing sequence and understood the role of endstops
  • Understood the importance of bed leveling and first-layer adhesion for a successful print
  • Learned about the Bowden vs Direct Drive extruder setups and their trade-offs

🔍 What We Learned

  • Identified all physical components of the FDM printer by name and function
  • Observed a live demonstration of the printer homing and heating up
  • Understood the role of each axis in building a 3D object layer by layer

Day 02

Machine Calibration & Settings

Going deeper into the printer — learning how to properly calibrate, load filament, and set up the machine so every print starts correctly and reliably.

  • Practiced manual bed leveling — adjusting the four corner knobs until the nozzle gap is consistent across the print bed
  • Used a piece of paper as a feeler gauge to set the correct nozzle-to-bed distance (Z offset)
  • Learned how to load and unload filament — heating the hotend to the correct temperature and feeding the filament through the extruder
  • Understood printer temperature settings: hotend temp (typically 200°C for PLA) and bed temp (typically 60°C for PLA)
  • Explored the printer's LCD control panel — navigating menus, running preheat, and controlling the axes manually
  • Understood print speed settings and the trade-off between speed and print quality
  • Learned how to perform a PID tuning calibration for stable temperature control

🔍 What We Learned

  • Learned about all the critical machine settings — temperatures, speeds, and offsets
  • Practiced bed leveling and understood why first-layer quality is critical to every print
  • Understood how to load filament and prepare the printer for a print job

Day 03

Slicing — CAD File to G-Code

The critical bridge between the digital CAD model and the physical printed part — learning how to use slicing software to translate an STL file into printer-ready G-Code instructions.

  • Understood what slicing means — dividing a 3D model into hundreds of thin horizontal layers that the printer builds one at a time
  • Installed and explored Ultimaker Cura — the primary slicing software used in the lab
  • Imported an STL file exported from Fusion 360 into Cura
  • Configured essential print settings: Layer Height (0.2mm standard), Infill %, Print Speed, and Support structures
  • Learned about infill patterns — Grid, Gyroid, Honeycomb — and how infill % affects strength vs print time
  • Enabled Supports for overhanging features and understood the 45° overhang rule
  • Explored Brim and Raft options for better bed adhesion on tricky prints
  • Exported the sliced file as G-Code and transferred it to the printer via SD card
  • Understood what G-Code is — a series of machine instructions (X/Y/Z movement, temperature, fan speed) that control every action of the printer

🔍 CAD → Slicer → Printer Workflow

  • Exported a Fusion 360 model as STL and imported it into Cura for slicing
  • Configured layer height, infill, and support settings for the model
  • Generated G-Code and understood how it controls the printer movement and temperature

Day 04

First Print — Project Day 1

Putting theory into practice — setting up and running the first print of our project. Starting with a test print and then moving to the actual project part.

  • Ran a test calibration cube first — a 20×20×20mm cube to verify dimensional accuracy
  • Observed the first layer going down and checked adhesion, width, and consistency
  • Learned how to pause and resume a print to change filament mid-print for multi-color effects
  • Monitored print progress and identified common issues: warping, stringing, layer shifting, and under-extrusion
  • Started printing Project Part 1 — the base component of the final project
  • Used the Tune menu during printing to adjust live flow rate and speed

🖨️ Project Work — Day 1

  • Printed and verified a calibration cube for dimensional accuracy
  • Began printing the first component of the final project
  • Monitored the print and adjusted settings in real time

Day 05

Project Continues — Part 2

Continuing the project — printing additional components, troubleshooting any issues from the first print, and refining settings for better results.

  • Reviewed the Part 1 print — checked for defects, measured accuracy with calipers
  • Adjusted slicer settings based on results — modified layer height and support density
  • Printed Project Part 2 — the secondary component of the assembly
  • Learned about post-processing — removing supports carefully, sanding, and dry-fitting parts together
  • Understood how tolerances matter in multi-part assemblies — added small clearances in the CAD model where parts fit together
  • Explored print-in-place concepts — designing hinges and joints that print assembled in one go

🖨️ Project Work — Day 2

  • Evaluated Day 1 print and made slicer adjustments for improvement
  • Printed the second project component and began post-processing
  • Dry-fitted parts together and verified assembly fit
